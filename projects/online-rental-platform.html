Web App

Online Rental Platform

A web platform for listing and renting houses, rooms and flats, presenting rental properties in an organized way and making it simple to explore available accommodation.

Role
Design & development
Type
Web application
Platform
Web browsers
Built with

Overview

Finding a place to rent is harder when listings are scattered and inconsistent. The Online Rental Platform brings houses, rooms and flats together in one place and presents every property in a clear, consistent format.

The focus was a simple, intuitive interface that lets renters explore available accommodation quickly, while keeping property listings, tenant details and bookings organized.

Key features

  • Property listings

    Houses, rooms and flats listed in one place with consistent details.

  • Easy exploring

    A simple way for renters to browse the accommodation that is available.

  • Tenant management

    Keeps tenant information organized alongside each property.

  • Booking process

    Streamlines the steps for booking or renting a property.

What I did

  • Planned how properties and their details are structured and organized.
  • Designed a clean, intuitive interface for browsing listings.
  • Built the pages and interactions with HTML, CSS and JavaScript.
